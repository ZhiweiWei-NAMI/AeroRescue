# 任务与意图驱动的 Agentic 通感算联合优化：研究版图与方向判断

调研截止：2026-10-30。用途：上层科学问题选题；本次未运行系统实验。

## 阅读结论

最值得保留的总问题是：**在任务意图、环境和资源都可能变化时，分布式智能体应如何联合决定获取什么新观测、交换什么信息、投入多少计算，以及何时采取行动？**

Token、KV cache、场景图、3DGS 是回答这个问题的候选机制，不能先把它们定为必要组件。可以评价各方向的问题重要性、已有工作密度和可检验性，但不能据此保证发表价值，也不能从有限检索证明“全球无人研究”。本报告给出六个上层方向，并明确推荐依据及不确定性。

## 1. 调研口径与证据边界

这是一轮跨领域范围调研，不是遵循完整 PRISMA 流程的穷尽性系统综述。覆盖任务/语义通信、网络化控制、协作感知、三维语义表示、世界模型、LLM 多智能体、缓存系统和 2025—2026 年 Agentic 网络工作。检索结合关键词搜索、官方会议页、arXiv 原文页和相关文献追溯。

文末列出 27 项直接打开核验的代表来源。阅读深度分为：**A：摘要/官方论文页；B：项目页的方法与演示说明；C：HTML 正文中可见的方法、案例或理论章节**。C 也不等于逐式证明复核、完整 PDF 精读或代码复现；部分网页输出被截断。跨论文指标不组成排行榜。

下文使用三种判断：**文献事实**是来源直接支持的内容；**研究推断**是从多个领域连接得到、尚待验证的判断；**待检验假设**是可以被实验推翻的主张。综述证明一个议题已被提出，不能证明相应系统已实现。

## 2. 首先修正此前讨论中的前提

| 此前表述或隐含前提 | 调研后的修正 |
|---|---|
| 传统 ISCC 只关心容量、PSNR；任务效用是 Agentic 新引入的 | 不成立。任务通信、网络化控制、VoI 已研究任务代价；ISAC 也涉及检测、定位、估计界和跨层权衡。[R1–R5] |
| 3D 重建与决策目标互斥 | 不成立。可联合优化，也可把重建作为辅助目标；关键是是否改善任务和资源前沿。 |
| 最后一个视觉 token 必然抹掉全部几何 | 过强。取决于编码器、训练目标、位置和解码方式。压缩会受率失真约束，但不能由“最后一个”直接推出具体丢失内容。 |
| 按任务选择少量特征就是新的核心贡献 | 已有成熟近邻；When2com、Where2comm、R-ACP、RDcomm 分别涉及通信触发、空间选择、任务压缩和率失真。[R6–R9] |
| 任务语义高斯天然更科研，甚至预示获奖 | 无依据。LangSplat 与 HAMMER 已提供语义高斯和多机器人在线地图；价值必须由新增能力证明。[R11–R12] |
| 计算就是压缩 KV，KV 天然是任务意图的充分表示 | 不成立。计算还包括识别、推理、规划、验证、预测；普通 KV 不等于经过任务充分性验证的压缩码。 |
| KVComm 已证明不同规模模型可直接共享认知状态 | 不成立。其直接证据是跨上下文复用与偏移对齐；跨模型表示、混合递归状态和物理任务需另证。[R15] |
| AirComp 只能聚合梯度，绝不可能用于神经推理 | 过强。它面向在信道中计算函数，某些特征聚合可适用；它不会自动成为完整 LLM 推理方案。[R3] |
| 加 LLM 或更换 prompt 就足以定义 Agentic 原生 | 不足。必须说明自主目标执行、反馈调整与资源决策带来了什么可测能力。固定任务 RL 也可闭环；Agentic 并非单一、统一的数学类别。 |

两个重要最近邻已经直接占据命名空间：**When Agentic AI Meets ISAC** [R22]、**AI-Agent-Native 6G / ISCC** [R27]。另有 **Agentic AI for ISAC** 案例 [R23]、**Agent-Native Token 通信** [R24]、**Wireless Context Engineering** [R25]。因此，不能把这些词组合本身当成创新。

### 通感融合要保留两种可能定位

**功能与决策层融合**：相机/热成像等独立传感器获取观测，网络交换信息，模型进行推理，任务反馈再决定感知与通信。这里的研究对象是协作感知、通信和计算的共同决策。

**物理层融合**：同一或协同无线信号承担通信与环境探测，包含真实的波形、带宽、功率、波束、回波和估计关系。若论文主张“通信接收信号同时重建环境”，必须明确接收的是载荷还是环境回波，以及重建依赖的测量模型。前者不能单凭命名证明后者。两种路线都可以有价值，不必现在强行放弃其中一种。[R2–R3]

## 3. 按此前八组问题依次回答

### Q1. 联合优化如何成立，需要通感算的固定兑换比吗？

**回答：不需要固定兑换比，需要共享任务目标、因果耦合和实际资源模型。**

可用受约束部分可观测团队决策作为起点。令 g 为任务意图，h_t^i 为智能体 i 当时可获得的历史，r_t 为资源状态。联合策略只能依据可访问的信息选择感知 u、通信 m、计算 c 与物理行动 a：

\[
(u_t^i,m_t^i,c_t^i,a_t^i)\sim\pi_i(\cdot\mid h_t^i,g,r_t^i).
\]

\[
\max_\pi\;\mathbb E[J_g(\tau)]\quad\text{s.t.}\quad
\mathbb E[B(\tau)]\leq\bar B,\;\mathbb E[E(\tau)]\leq\bar E,\;
\Pr(T_{\rm mission}>D)\leq\epsilon.
\]

这是研究建模模板，不是本报告推出的新定理。任务效用可含目标确认、定位、覆盖与时间；通信预算要区分上行、下行和共享信道；计算延迟、传输延迟会改变后续环境与观测。若多个行动耗时不同，用半马尔可夫或连续时间建模，不能把“再推理一轮”当作世界暂停。

**文献事实**：VoI 控制理论已把是否发送数据与控制代价关联；RDcomm 已针对协作感知定义任务损失与通信的关系。[R4–R5、R9] **尚待验证的延伸**：变化意图、主动观测、异构模型和推理预算共同存在时，哪些策略可以分开设计，哪些必须耦合？

联合优化不要求一个大网络端到端训练。分层、交替和事件触发方法都可能是联合设计。反过来，写一个包含三项加权损失的公式，也不自动产生新的科学问题。

### Q2. 任务中心通信应该选择什么，注意力或熵够不够？

**回答：应选择对接收者后续任务有增量价值的信息；token 是其中一种载体。**

When2com 学习何时及如何组织通信，Where2comm 学习空间稀疏共享，R-ACP 使用任务相关压缩并考虑校准、时效与信道，RDcomm 考虑任务失真及接收者已有信息。[R6–R9] “传相关区域”“减少冗余”已是研究主线。

更一般的科学判据是：接收者在已有历史 h_j、任务 g 下，收到消息 m 后，后续任务价值增加多少？可概念性写为

\[
\operatorname{VoI}(m\mid h_j,g)=V_g(h_j\oplus m)-V_g(h_j),
\]

其中 V 必须包含实际到达时间、后续决策与机会成本；发送者通常也不知道接收者的完整历史，所以这个差值不能当作免费可用的标签。

注意力、熵、显著性都是代理指标，不是任务收益的普适证明。高熵区域可能与任务无关；低置信目标反而可能最值得核实。感知结果还可能互补或协同，逐 token 独立打分可能漏掉组合价值。

**研究推断**：较有价值的问题是“如何在变化任务与未知同伴知识下学习消息的决策价值”，包括请求、补充与停止通信，而不只是再设计一个打分器。筛选开销也必须计入；不要预设深层特征比硬件编码的视频更省时省电。

### Q3. 上行 token 与下行 KV 的非对称设计是否合理？

**回答：可以研究，但上下行载荷应独立竞争，不能预设必须采用这对组合。**

上行候选包括压缩图像/视频、裁剪区域、目标轨迹、稀疏特征、地图增量；下行可用子任务、结构化约束、世界状态更新、预测或计算状态。上行用于“让中心知道”，下行用于“让端侧行动”，两者不必采用同一种表示，也不必固定一种表示。

CacheGen 直接指出 KV 张量传输会造成网络延迟，并研究压缩和带宽适配。[R16] 对缓存路线，至少比较：

\[
T_{\rm cache}=T_{\rm produce}+T_{\rm encode}+T_{\rm network}+T_{\rm adapt}+T_{\rm fuse},
\]

与发送紧凑任务信息后本地处理的完整时间。多接收者、广播、预取和多次复用可摊销成本；单次 TTFT 不能代表任务闭环收益。

**量级示例，非新实验**：按此前核验的 Qwen3.5-2B 全注意力部分配置，BF16 KV 为每 token 12 KiB；1,000 token 约 11.72 MiB，仅在理想 10 Mbps 链路上传输就约 9.83 秒，尚未计混合模型递归状态、编码和协议成本。文本 token ID 通常仅占少量字节，但词表可能超过 uint16，不能一律写成“每 token 两字节”。

可检验的上层问题是：**什么任务信息应以显式消息传输，什么计算状态值得跨设备复用，其收益区域如何随带宽、模型差异和复用次数变化？**

### Q4. 怎样可视化更有科研说服力，必须用 3DGS 吗？

**回答：选择能显示科学主张的可视化；3DGS 可以是表示，也可以只是展示底图。**

LangSplat 已将语言特征绑定到高斯，HAMMER 已从异构机器人异步流构建在线语义高斯地图。[R11–R12] 所以“高斯更漂亮”“关键区域更清晰”不能独立证明通感算收益。也不能预画出本方法成功、JPEG/H.265 失败的结果。

建议让同一场景同时呈现：任务意图与当前问题、已观察/未观察/已过时区域、信息来自哪台机器、何时通信与推理、这些决策如何改变行动。旁边再给实际资源—任务收益曲线及失败案例。三维空间、语义关系和事件时间线可以联动，但不是现在必须实现的产品要求。

如果 3DGS 是算法贡献，需检验它相对三维 occupancy、几何地图或场景图的独立增益。如果它只是方便看懂实验，明确作为展示工具即可；科研性来自对主张的证据。

### Q5. 感知结果究竟应该是视觉、三维几何、场景关系，还是世界模型？

**回答：它们是不同层次，不是必须二选一；关键是为决策保留哪些信息。**

| 层次 | 回答的问题 | 典型对象 | 不能自动保证的能力 |
|---|---|---|---|
| 观测 | 传感器看到什么？ | 图像、深度、热成像、无线测量 | 全局位置和遮挡后状态 |
| 估计/信念 | 世界可能是什么，哪里未知？ | 目标分布、occupancy、概率地图 | 采取行动后的变化 |
| 关系与任务状态 | 谁在哪里、可达吗、任务做到哪？ | 三维场景图、拓扑、可供性 | 细密几何和精确动力学 |
| 预测模型 | 如果执行动作，会发生什么？ | 动作条件转移、奖励/观测预测 | 在新环境中预测可靠 |

ConceptGraphs 展示开放词汇三维场景图支持语言查询和规划；DreamerV3 展示学习模型并在想象中改善行为。[R10、R13] 这两条路径不能混称为已经解决同一问题。静态地图可以是广义世界表示，但不能仅因可新视角渲染就声称拥有动作条件预测能力。

**较有价值的科学问题**：在给定任务族中，什么共享表示足以保持高质量决策，又能减少同步、感知和计算成本？当任务从“找人”变成“确认撤离通路”时，旧表示还够不够？这里的“充分”应以决策损失或价值差衡量，不能仅由视觉效果判断。除非论文研究真实非平面空间，不应把强基线限制为纯二维图。

### Q6. 计算是不是 KV 意图压缩，中心 KV 应怎样供端侧使用？

**回答：计算是对信息的处理和对行动的推演；KV 是其中一种实现状态，并非计算的定义。**

需要区分三个研究目标：**语义消息**为了把有用信息交给同伴；**计算复用**为了减少重复前向计算；**状态迁移**为了让另一模型继续处理。这三者可同时发生，但收益来源与适配条件不同。[R15–R20]

KVComm 证明跨前缀的缓存可以通过 anchors 校准以减少预填充；CacheBlend 针对 RAG 片段缓存组合中的上下文依赖；跨模型 KV 映射和 RaReCache 表明迁移有希望，也有模型对失败和选择性重算需求。[R15、R17、R19–R20] 它们没有证明 Qwen3.5 混合状态的 2B→0.8B 任务字典已经有效，更没有证明读字典优于收到结构化场景更新。

按照你此前的要求，可以把中心状态视为**可查询的外部增强字典**，不要求恢复端侧原生状态。这样研究目标应是查询对决策与资源的增益，而非两模型状态语义等价。Cross-attention、适配后前缀或检索增强是候选接口，不必现在选定；另起外部记忆接口也不应自动称为“原生 KV 无损继承”。

**待检验假设**：在异构模型、动态任务和多次查询条件下，共享某类可复用计算结果能改善团队资源—任务前沿。应允许实验发现：文本/结构化状态更划算。

### Q7. 信道差时多本地计算、信道好时中心推理，是否是核心贡献？

**回答：动态协作计算值得研究；单独“按信道卸载”已不足，且信道差不必然意味着多算。**

BEST-Route 已联合选择模型与生成样本数；Wireless Context Engineering 已讨论推理预算下组织任务相关上下文。[R21、R25] 因此“动态路由大小模型”“筛选上下文”需要进一步增量。

关键应是识别瓶颈来源：**缺少观测、同伴持有互补信息、本地模型处理不足，还是任务已经足够明确？** 对应动作可能是再看、询问、调用更强模型、增加验证，或立即行动。在输入完全相同的情况下，更多推理不会创造新的环境证据；它可能用先验改善推断，也可能只增加过度自信与延迟。

有价值的扩展是统一这些选择的边际任务收益与成本，而非固定“弱网→更多本地思考”的规则。闭环应考虑时限和环境在计算期间的变化。断网自主性可以是评价条件，但不必引入繁重的分支日志、一致性协议或认知合并状态机。

### Q8. 怎样做消融，才能区分联合优化、LLM、KV 和三维表示的贡献？

**回答：比较能力和资源前沿，不能先规定某种基线必然失败。**

| 想检验的主张 | 对照应该包含什么 | 支持主张所需证据 |
|---|---|---|
| 联合设计有效 | 分别优化、分层协调、联合策略 | 相同资源下任务改善；不同预算下前沿仍有改善 |
| 任务/意图有效 | 固定通用任务策略、正确意图、被打乱的意图、变化意图 | 收益确实依赖任务条件，而非更大模型或额外信息 |
| Agentic/基础模型有效 | 规则、优化/MPC、RL/MARL、仅意图解析、完整闭环 | 在未见任务组合和反馈变化时仍有能力增益 |
| latent/KV 有效 | 同信息范围的文本、结构化消息、特征和缓存 | 同时计发送、接收、适配、生成、通信及任务质量 |
| 三维表示有效 | 三维 occupancy/几何地图、场景图、特征场、高斯 | 给强几何基线同样机会后，仍有独立任务或资源收益 |
| 协作有效 | 单体、固定通信、事件通信、中心化上界 | 控制观测权限与计算预算后仍存在协作收益 |

Where2comm/RDcomm 是感知通信近邻，不应被强行要求原论文不提供的飞行规划；要接入一致的规划后端。文本基线可发送数字坐标、置信度、时间戳与关系，不能限制成含糊自然语言。视频基线也应有合理的编码、关键帧、裁剪与自适应码率。

主指标按任务定义：期限内成功/目标确认/定位或路径质量，附时间、字节、能耗或设备时间。重复任务和随机环境应报告方差或区间；神经模型的置信度不是现实证据真伪的替代。负结果同样用于界定方法的适用范围。

## 4. 六个有研究价值的上层方向

以下方向不是六个可以机械堆叠的模块，也不要求一篇论文全部覆盖。A 是共同决策的理论主线；B—F 可各自成为主要科学主张。价值判断依据问题的重要性、区别于已有工作的空间、可证伪性，以及与原始目标的联系；不是对会议录用率打分。

### A. 有限资源下的分布式主动决策：何时再看、再问、再算？

**核心问题**：团队当前任务的不确定性应通过新传感、同伴信息、额外推理还是立即行动来处理？如何共同选择，而不是各自优化相机、压缩率和卸载比例？

**动机实例**：无人机发现疑似人员，但证据不清。转动相机、请求另一台观察、让中心分析现有图像，是三种不同的信息处理行动。其收益取决于观测互补、模型能力、通信时延和目标是否正在移动。

**已有到哪**：VoI 已研究通信与控制；协作感知已研究任务通信失真；路由工作已研究模型与推理预算。[R4–R9、R21] 这些基础均不是新发明。

**可能的增量**：在部分可观测、变化任务、异构模型和非零决策耗时下，建立统一的边际任务价值估计，并解释或验证何时模块分离产生明显损失。优先寻求可分析子问题和可复现闭环，而非声称解出一般 Dec-POMDP。

**可证伪主张**：跨资源预算和未见任务条件下，联合选择稳定改善分治/分层强基线的任务—资源前沿。若收益只来自更多计算、更多信息或单个特定场景，则主张不成立。

**判断**：与“通感算联合优化”的动机最一致，科学问题清楚，优先保留。一般的主动感知与元推理并不新；新颖性须落在上述耦合与可推广规律上。

### B. 面向变化任务的共享世界信念：团队究竟需要共同知道什么？

**核心问题**：在通信与存储受限时，分布式智能体应维护怎样的世界表示，才能既支持当前任务，又避免过早压缩掉后续任务所需的信息？

**动机实例**：搜人只关注目标存在；规划撤离还需通路与危险；确认后续搜查还需哪些区域真正观察过。面向一个任务训练的选择器可能把另一个任务的重要证据永远丢掉。

**已有到哪**：ConceptGraphs 支持语义关系与规划；LangSplat 支持三维语言查询；HAMMER 支持异构多机器人在线语义地图；DreamerV3 展示可用于行为学习的预测模型。[R10–R13]

**可能的增量**：把任务条件下的决策充分性、跨智能体互补、信息过时与不确定性放在同一个共享表示中；研究何时扩展、细化、遗忘或重新观测。若加入预测，应检验动作条件后果，而非只提供漂亮的新视角图。

**可证伪主张**：在任务切换与观测预算相同时，共享表示能以更低同步/重建/查询成本保持决策质量。与任务无关地图、任务专用特征、三维 occupancy 和场景图共同比较。

**判断**：最贴近你“协作感知最终产物是什么”的疑问，具有独立科学问题，也容易形成有解释力的三维可视化。仅提出语义高斯或把几个表示拼接起来，增量不足。

### C. 异构智能体的协作推理与认知资源分配：什么值得共享计算结果？

**核心问题**：团队的计算能力如何组成可合作的整体？哪些中间结果值得跨模型共享，哪些应本地重算；已有计算如何被不同任务重复利用？

**已有到哪**：KVComm、CacheGen、CacheBlend 分别处理上下文复用、传输压缩和缓存组合；跨模型映射及 RaReCache 进一步研究迁移与重算；latent 通信已经有专门综述。[R15–R20]

**可能的增量**：研究协作信息和重复计算的分界，把模型差异、通信成本、任务分工、共享记忆和推理预算纳入同一资源策略。中心状态可以是可查询字典，无需复制端侧全部内部状态。

**可证伪主张**：在同信息权限下，共享某类中间结果的策略在一定任务—带宽—复用区域优于显式消息与独立推理，并能准确识别无收益区域。不能仅凭缓存注入改变 logits 证明有效。

**判断**：有研究价值，也与已有原型联系最紧。但 latent/KV 领域已快速拥挤，而且系统净收益风险较大；应以“分布式协作计算”为方向，避免退化成一个适配器或缓存压缩器。最新跨模型论文不自动适用于 Qwen3.5 混合递归架构。

### D. Agent 原生的交互式任务通信：网络如何组织协作，而不只是运送载荷？

**核心问题**：通信动作应如何表达请求、确认、补充和终止，才能让团队以少量交互建立足够的共同认知？何时推送，何时由接收者拉取，何时值得多一轮询问？

**已有到哪**：When2com/Where2comm 已学习通信策略；RDcomm 已显式考虑接收者侧信息；Agent 网络综述与 JTCM 已讨论意图、语义和 token 原生通信。[R6–R9、R24、R27]

**可能的增量**：研究信息的接收者依赖性、消息之间的协同性、任务依赖与多轮反馈成本。交互不是免费 side information；每次请求和意图同步都应计入字节、时延及处理开销。

**可证伪主张**：在同总资源下，交互式协议优于一次性特征上传和强事件通信策略；收益来自减少错误协作、过时与重复信息，而非把确认开销忽略。

**判断**：通信/网络学科的独立大方向。仅换成 token、增加一个消息 schema 或新命名协议还不足；需要交互策略、任务完成与网络效率之间的新结论。

### E. 面向开放意图的通感算通用策略：能否不为每个任务重新设计系统？

**核心问题**：面对未见任务组合、优先级变化、节点能力变化和预算变化，系统能否从意图推导可执行的感知、通信和计算安排？基础模型提供的究竟是语言入口，还是跨任务组合与适应能力？

**已有到哪**：Inner Monologue 已验证语言反馈改善具身执行；Agentic ISAC 已给出框架与案例；Wireless Context Engineering 与 Edge General Intelligence 已讨论任务上下文和有限资源。[R14、R22–R23、R25–R27]

**可能的增量**：从固定标签的 task-oriented 策略，推进到对任务结构、约束和工具能力进行组合泛化的资源策略。训练方法可以是模仿、强化学习、规划监督或分层组合；“用了哪一种训练器”本身不是上层贡献。

**可证伪主张**：在未见任务组合、约束与资源条件下，完整策略优于“LLM 只解析意图 + 同一个经典调度器”和任务条件 RL/MARL，且包含推理成本。

**判断**：最能回答“为什么需要 LLM/Agentic”，值得保留。但“开放意图”必须操作化；prompt 改写不等于任务泛化。评价难度比固定搜救任务更高，不能用一个已见场景宣称通用智能。

### F. 具身网络与物理环境协同：行动能否同时改善任务、感知和通信？

**核心问题**：无人机位置、视角、遮挡和队形同时改变看到的证据、链路和到计算中心的可达性。任务策略如何利用这种共同几何？若引入真实 ISAC，哪些任务相关物理量值得探测和计算？

**动机实例**：飞到高处既可观察被遮挡区域，也可改善中继链路，但会花时间和能量；绕行的价值可能来自增加团队的信息与算力可用性，而非单机路径更短。

**已有到哪**：物理 ISAC 已包括感知辅助通信和通信辅助感知；Agentic ISAC 的已有案例还直接优化波束、速率和 CRB。[R2、R22–R23] 这不是用 LLM 就从零出现的领域。

**可能的增量**：在任务层效用下联合行动、观测与网络可达计算；或把任务相关感知需求落实到真实波形/采样/波束与推理预算。两条实施路线要分别说明，不能用视觉图像上传冒充同波形感知。

**可证伪主张**：共同环境模型或联合行动策略在等任务预算下优于独立导航、链路调度和计算路由；若宣称物理融合，需要测量模型和物理资源对照。AirComp 只在适合的函数聚合和误差容忍条件下作为候选算子。

**判断**：若你要保留通信学科和“通感融合”的物理联系，这是应保留的大方向。但既有 UAV/ISAC 联合优化很密集，LLM 输出一组传统参数通常增量有限；当前调研不足以为某个具体跨层方案认定新颖性。

## 5. 如何选择主线：条件判断而非机械排名

| 方向 | 为什么值得研究 | 主要已有工作压力 | 条件判断 |
|---|---|---|---|
| A 主动联合决策 | 直接解释三类资源何时替代、何时互补 | VoI、主动感知、元推理、POMDP 均有历史 | 优先；必须找到新的耦合规律或可推广闭环能力 |
| B 共享世界信念 | 解决协作感知输出及变化任务的信息需求 | 场景图、语义 3DGS、多机器人地图已存在 | 优先；用任务充分性与更新成本证明价值 |
| C 协作推理 | 把计算本身视为团队资源，接近现有原型 | latent 通信、KV 迁移和缓存系统很活跃 | 值得保留，收益风险较高，不先锁死 KV |
| D 交互式任务通信 | 研究谁需要什么、何时询问与同步 | 学习通信与接收者侧信息已有直接近邻 | 有价值；须超越单轮特征选择和命名协议 |
| E 开放意图泛化 | 为基础模型与 Agentic 提供必要性检验 | Agentic 网络及上下文框架快速增长 | 有价值；须使用实质未见任务与约束 |
| F 具身/物理协同 | 通过共同环境和行动落实真实耦合 | 经典 UAV/ISAC 与跨层优化很密集 | 有条件保留；需要明确物理主张及新增能力 |

**本轮最有依据的建议**：将 A 作为联合优化动机，将 B 或 C 选作主要科学对象。B 适合主攻分布式感知与共享世界；C 适合主攻异构模型协作计算。D、E、F 不是必须附加的卖点，也可以分别成为另一条主线。不要一篇论文同时承诺六类突破。

建议的总问题表述是：

> 面向变化任务和有限资源的分布式具身智能，如何联合获取新证据、交换互补信息并分配推理计算，以在任务时限内维持高质量团队决策？

若选 B，可进一步聚焦：

> 任务变化时，团队应共享和更新怎样的世界信念，才能同时控制观测、通信与推理成本？

若选 C，可进一步聚焦：

> 异构智能体之间，什么信息应被显式传达，什么中间计算值得共享，何时独立重算反而更优？

这三个表述均不强制采用某个模型大小、token 选择器或高斯表示。

## 6. 不能从这轮调研推出的结论

尚不能声称六个方向中的任何一个“完全空白”，也不能声称 Agentic 一定优于 RL、KV 一定优于文本、三维高斯一定优于三维 occupancy。也没有任何本项目闭环结果证明某个压缩率、延迟或搜救收益。

存在一些值得关注但本轮未充分覆盖的邻近领域：多智能体学习通信与 emergent communication、分布式信息瓶颈与交互编码、主动 SLAM/信息路径规划、理性元推理与计算价值、真实救援通信与多传感器数据。它们可能削弱某个细化命题的新颖性；目前方向判断以问题与已核验最近邻为边界，不把未覆盖区域说成空白。

## 8. 对后续研究讨论的边界

当前足以先确定问题空间，不足以锁定“中心必须下发 KV、端侧必须选 token、共享地图必须是 3DGS”。后续任何路线都应能回答：**没有新增证据时，计算改善的是什么；同伴已有信息时，通信增加的是什么；任务改变时，表示遗失的是什么；资源减少时，系统愿意牺牲的是什么？**

这些问题能够跨越某个具体技术模块，才符合本轮要寻找的上层研究方向。
